# D&D 3.5 Core Quill Sketches — Transparent WebP

77 character sketch assets converted from the corrected/centered set.

Properties:
- 512 × 512 pixels each
- transparent background
- same centered composition as the corrected SVG set
- single dark sepia quill linework
- lossless WebP encoding
- filenames preserved as `race_class.webp`

Examples:
- `human_fighter.webp`
- `half-orc_wizard.webp`
- `half-elf_bard.webp`
- `gnome_druid.webp`

Recommended HTML usage:

```html
<img src="/characters/half-orc_wizard.webp"
     alt="Half-Orc Wizard"
     class="character-sketch">
```

All assets keep identical dimensions, so swapping images will not move the page layout.
